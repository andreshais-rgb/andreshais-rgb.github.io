Política de Privacidade – Escala Igreja

Última atualização: 23 de novembro de 2026.

1. O que é o aplicativo

O Escala Igreja é uma ferramenta de uso interno, executada no computador do organizador, que gera a escala mensal de trabalhos da igreja e a envia por e-mail aos responsáveis para validação.

2. Dados acessados

Com a autorização do titular da conta Google, o aplicativo usa a API do Gmail para:

  • Enviar e-mails (escopo gmail.send): apenas a mensagem com o PDF da escala, para os destinatários configurados pelo organizador.
  • Ler e-mails (escopo gmail.readonly): apenas as respostas ao e-mail da escala, localizadas pelo assunto, para identificar os ajustes pedidos.

O aplicativo não apaga, não altera e não move mensagens.

3. Uso e armazenamento

Os dados são processados somente no computador do organizador. O token de autorização fica salvo localmente nesse computador. Nenhum dado é enviado a servidores próprios, vendido, compartilhado com terceiros ou usado para publicidade.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Revogação do acesso

O titular pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.
